# StreamLab

Simulador local de historial musical con interfaz en español. El archivo descargado contiene datos ficticios y no acredita escuchas reales. Es un proyecto independiente de Spotify y stats.fm.

## Publicar en GitHub Pages

1. Crea un repositorio público en GitHub, por ejemplo `streamlab`.
2. Sube `index.html` a la raíz del repositorio.
3. Ve a **Settings → Pages → Build and deployment**, selecciona **Deploy from a branch**, rama **main**, carpeta **/(root)** y guarda.
4. Abre `https://TU_USUARIO.github.io/streamlab/` cuando GitHub termine la publicación.

No necesita compilación ni servidor. Puedes abrir `index.html` localmente para probarlo. No requiere claves, contraseñas ni API de Spotify.

Para importar tu historial auténtico a stats.fm, sigue la [guía oficial](https://support.stats.fm/es-ES/docs/import/spotify-import/); requiere stats.fm Plus y los archivos originales de Spotify. No se garantiza la aceptación de archivos de prueba.
